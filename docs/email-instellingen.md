## Gmail (als extra account toevoegen)

1. Gmail → profielfoto → **Een ander account toevoegen**
2. Scroll naar beneden → **Andere**
3. Vul e-mailadres in → volgende → kies **IMAP**
4. Inkomende server: `mail.baarnsmannenkoor.nl` poort `993` SSL/TLS
5. Uitgaande server: `mail.baarnsmannenkoor.nl` poort `587` STARTTLS
6. Gebruikersnaam = volledig e-mailadres, wachtwoord uit KeePass

## Outlook

1. Bestand → Account toevoegen → e-mailadres → Verbinden → **IMAP**
2. Inkomend: `mail.baarnsmannenkoor.nl` poort `993` SSL/TLS
3. Uitgaand: `mail.baarnsmannenkoor.nl` poort `587` STARTTLS

## iOS (iPhone/iPad)

1. Instellingen → Mail → Accounts → Toevoegen → **Overig** → E-mailaccount
2. IMAP kiezen
3. Inkomend + uitgaand: `mail.baarnsmannenkoor.nl`, poorten 993 / 587

## Android (Gmail-app)

1. Gmail → Instellingen → Account toevoegen → **Overig** → Handmatig instellen → IMAP
2. Inkomend: `mail.baarnsmannenkoor.nl` poort `993` SSL/TLS
3. Uitgaand: `mail.baarnsmannenkoor.nl` poort `587` TLS
